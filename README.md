# Elektrik İzolatörlerinde Hasar Tespiti ve Sınıflandırılması

## Proje Hakkında
Bu proje, derin öğrenme ve Evrişimli Sinir Ağları (CNN) kullanılarak elektrik izolatörlerinin görüntüler üzerinden hasarlı ve hasarsız olarak sınıflandırılmasını amaçlamaktadır.

## Kullanılan Teknolojiler
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- scikit-learn

## Veri Seti
Projede kullanılması planlanan veri seti CPLID (Chinese Power Line Insulator Dataset) olarak belirlenmiştir.

Veri seti: https://github.com/InsulatorData/InsulatorDataSet

## Kaynak Kod
Python kodu: izolator_hasar_tespiti.py

## Proje Durumu
Kodun gerçek veri seti üzerinde çalıştırılması ve performans sonuçlarının değerlendirilmesi gerekmektedir.
